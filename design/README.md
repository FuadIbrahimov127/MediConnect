# UI prototipləri

Vizual dizayn mənbəyi. Ekranlar `.dc.html` formatındadır və `support.js` runtime-ı ilə işləyir — eyni qovluqda saxlanmalıdır. Faylı brauzerdə birbaşa açmaq kifayətdir.

| Fayl | Ekran |
|---|---|
| `MediConnect.dc.html` | Ümumi / giriş |
| `MediConnect Ana Səhifə.dc.html` | Ana səhifə |
| `MediConnect Həkim Axtarışı.dc.html` | Həkim axtarışı |
| `MediConnect Həkim Profili.dc.html` | Həkim profili |
| `MediConnect Randevu.dc.html` | Randevu alma |
| `MediConnect Şəxsi Kabinet.dc.html` | Pasient kabineti |
| `MediConnect Həkim Paneli.dc.html` | Həkim paneli |
| `MediConnect Klinika Admin Paneli.dc.html` | Klinika admini paneli |
| `MediConnect Super Admin Paneli.dc.html` | Super admin paneli |
| `support.js` | Prototip runtime-ı |
